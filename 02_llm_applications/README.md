Build a simple LLM application that answers financial-risk questions using structured prompts and reliable outputs.

## Learning Topics

- Prompt engineering
- System and user messages
- Few-shot prompting
- Structured outputs
- JSON responses
- Classification
- Summarization

- Validation

- Evaluation
